# 📊 Meu App Contas — Dashboard Financeiro

Uma aplicação web interativa de **Gestão e Controle Financeiro Pessoal**, desenvolvida com **HTML5**, **CSS3** e **JavaScript Vanilla**. O projeto permite o acompanhamento de receitas, despesas e saldo em tempo real, organizando informações financeiras através de uma interface moderna e intuitiva.

---

## 🌐 Demo Online

Acesse o projeto publicado: https://diegok29.github.io/meu-app-contas/

---

## 🚀 Funcionalidades

- **Resumo Financeiro Automático:** Cáclulo instantâneo de Entradas (Receitas), Saídas (Despesas) e Saldo Total.
- **Gestão de Lançamentos:**
  - Adição de novos registros com descrição, valor e tipo (Entrada/Saída).
  - Remoção/exclusão de transações.
- **Persistência Local (LocalStorage):** Os dados inseridos permanecem salvos no navegador do usuário mesmo após fechar ou recarregar a página.
- **Interface Responsiva & Modos de Visualização:** Layout otimizado para dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para apresentação dos componentes e formulários.
- **CSS3:** Estilização moderna, variáveis CSS, Flexbox/Grid e design responsivo.
- **JavaScript (ES6+):** 
  - Manipulação dinâmica do DOM.
  - Event Listeners e validação de formulários.
  - Armazenamento com API de `localStorage`.
